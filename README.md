# Hamiltonian Escape
[Japanese (日本語版)](./README.ja-JP.md)

![Cover image](JamSubmission/cover.png)

Hamiltonian Escape is a simple 2D grid-based puzzle game based on the concept of [Hamiltonian paths](https://en.wikipedia.org/wiki/Hamiltonian_path), where for each room, you have to traverse each floor in the room at most once before reaching for the goal/exit.

The game was made using C++ and [Raylib](https://www.raylib.com/) library, and compiled for HTML5 via [emscripten](https://emscripten.org/).<br/>
The background music was made using [PixiTracker](https://warmplace.ru/soft/pixitracker/).

This game was made as an entry for [JameGam15 game jam](https://itch.io/jam/jame-gam-15), with the theme of "No Going Back", which ran from January 25, 2022 - January 30, 2022.

You can play the game in a browser [here](https://jayzonty.itch.io/hamiltonian-escape).
